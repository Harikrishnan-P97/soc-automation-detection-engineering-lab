# Detection Engineering

This directory contains the custom detection content developed for the SOC Automation & Detection Engineering Lab.

The detections were designed to simulate real-world Security Operations Center (SOC) monitoring by identifying suspicious endpoint, authentication, web application, and network activity using telemetry collected from Windows Event Logs, Sysmon, ModSecurity, Suricata IDS, and firewall logs.

Each detection includes documented objectives, telemetry sources, detection logic, MITRE ATT&CK mappings, validation procedures, and sample alert outputs.

---

## Detection Engineering Methodology

The detection development process followed a structured workflow:

1. Simulate adversary activity within the lab environment.
2. Collect telemetry from relevant log sources.
3. Identify observable indicators of compromise (IOCs) and behaviors.
4. Develop detection logic using Splunk Search Processing Language (SPL).
5. Validate detections through controlled attack simulations.
6. Tune alert fidelity and reduce false positives.
7. Map detections to MITRE ATT&CK techniques.
8. Integrate alerts into automated SOC investigation workflows.

## Validation Approach

All detections were validated using controlled attack simulations performed within the lab environment.

Validation activities included:

* Credential dumping using Mimikatz
* Suspicious PowerShell execution
* Post-exploitation reconnaissance commands
* Data exfiltration simulations
* Authentication brute-force attacks
* SQL Injection attacks against DVWA
* Cross-Site Scripting (XSS) attacks
* Command Injection attacks
* Network scanning and suspicious connection activity
